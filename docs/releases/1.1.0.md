## Clean installation and restart

A separate Windows copy in an accented path began without dependencies, .env.local, .local, .next or a database. One `npm start` installed 46 locked packages, generated private configuration, selected available local ports, initialized PostgreSQL, migrated, seeded, compiled and served the application. Registration created seven accounts. The guided SO-1042 closeout persisted its educational invoice at COP 599,770.

After stopping the launcher and starting it again, dependency installation and compilation were skipped. The same authenticated session, scenario, invoice ID and cost remained available. Existing project instances were not modified. Generated credentials and test session cookies are not committed.

The exercise exposed two Windows compatibility conditions: newline-only legacy migration checksum differences and transient recursive build-directory locks. Equivalent LF/CRLF migration contents are accepted without editing existing records. The build-only retry is restricted to recursive mkdir EPERM/EACCES inside .next and remains bounded; real SQL edits and persistent errors still fail.

## Limits

Vehicle placement is illustrative, not physical bay tracking. Equipment observations and the policy experiment are synthetic; energy remains an estimate. This acceptance run is not real-world operational validation, a participant usability study, a physical-device certification or a Docker deployment test. No independent human review is claimed.
