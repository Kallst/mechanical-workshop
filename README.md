# Mechanical Workshop

A full-stack heavy-vehicle workshop management and simulation project grounded in Systems Theory.

## Project status

Repository initialized. Analysis, design, implementation, and verification will progress through feature branches and pull requests into `develop`. Stable releases will be promoted to `main`.

## Language

All software interfaces, source code, technical documentation, issues, pull requests, and commits use English. The academic presentation and spoken explanations use Spanish. Preserve personal names, including accents.

## Development workflow

`feature/*` -> `develop` -> `release/*` -> `main`

Hotfixes branch from `main` and are integrated into both `main` and `develop`.
